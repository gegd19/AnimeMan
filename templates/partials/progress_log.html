还差几步就可以开始整理

检测到尚未完成基本配置。

  1. 获取 TMDB API Key

    在 TMDB 官网注册并申请 API 密钥（免费）。

  2. 填写路径和密钥

    在「设置」里填入 TMDB API Key、源文件夹，以及剧集和电影的目标文件夹。

  3. 保存并测试连接

    点击「保存配置」，再点「测试连接」确认能访问 TMDB。

  4. 开始处理

    点击顶部的「开始处理」，AnimeMan 会扫描源文件夹并整理到媒体库。

  5. 启用 AI 解析（可选）

    文件名不规范时由 AI 辅助识别。需要填写 AI API Key；未填写时自动回退到规则解析。建议同时开启「文件夹批量解析」以节省调用次数。
